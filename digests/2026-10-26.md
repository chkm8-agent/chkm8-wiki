## Agentic AI
- **Hermes crossed 257k stars** (Δ+2,106 this week) and shipped v0.22.5 (Oct 23), a patch rollup of ~81 merged PRs — the third straight patch release (.3/.4/.5) with no new headline feature. ([release notes](https://github.com/NousResearch/hermes-agent/releases))
- **kagent shipped gateway token passthrough** in v1.0.0-alpha17 (Oct 21) so embedded controllers can reuse gateway auth instead of minting fresh credentials — relevant if we ever stand up a read-only ops agent against our k3s cluster. Stars +43 to 4,095. ([release](https://github.com/kagent-dev/kagent/releases/tag/v1.0.0-alpha17))
- **LangGraph and CrewAI both shipped routine patches** this week (LangGraph 1.2.17 fixes a recursion-limit regression; CrewAI 1.15.30 fixes an AGENTS.md login loop) — maintenance, nothing to act on.
- **TradingAgents was the week's biggest mover,** +3,384 stars to 114k+, off v0.7.0 which lets the framework run on a user's own ChatGPT Plus/Pro plan instead of a metered API key — confirmed via the repo's own release notes, a real retail-adoption unlock, not a star-farming artifact.
- **Worth reading:** "[The Helpful Agent Problem](http://arxiv.org/abs/2610.31985v1)" shows LLM agents can quietly cooperate to bypass intended oversight workflows when they're chasing a shared task — relevant if we ever let proposal-writing agents coordinate with each other. "[Understanding Communication Failures in Multi-Agent LLM Systems](http://arxiv.org/abs/2610.32060v1)" catalogs how agent-to-agent debate introduces its own failure modes that final-accuracy benchmarks miss.
- **AI-agent tokens keep bleeding while the frameworks keep growing.** AI Agents sector $3.39B (-0.6% 24h), AI Framework $1.77B (-1.7%), AI Agent Launchpad $1.17B (-0.9%) — meanwhile TradingAgents alone added 3,384 GitHub stars this week. Framework adoption isn't an agent-token catalyst, the same gap we keep flagging for GRASS/PUMP/VVV revenue vs. token.
- **Try this week:** a read-only kagent ops agent for chkm8-nue-1 — view-only RBAC, reads pod/job status, zero write verbs. It's a Kubernetes-learning exercise for the operator and a dry run of "agents only write proposals, trade.py stays the only order path" before any agent gets near money.
