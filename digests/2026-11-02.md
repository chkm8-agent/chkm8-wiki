## Agentic AI
- **TradingAgents is the week's outlier: +4,421 stars** (to 119,838) on **v0.7.1** (Oct 27), which fixes decisions
  being scored on anything but final closes and makes scoring settle correctly across long market holidays — plumbing
  fixes, but the star growth (vs. a few hundred for most repos this week) suggests this framework is getting real
  adoption traction beyond hype. ([github.com/TauricResearch/TradingAgents](https://github.com/TauricResearch/TradingAgents/releases/tag/v0.7.1))
- **kagent hits v1.0.0-rc1** (Oct 30), its first release-candidate toward a stable 1.0 — notable because we've
  flagged "deploy a read-only kagent ops agent on chkm8-nue-1" as a Try-this-week item twice before without acting;
  an rc1 means the CLI/API surface is stabilizing, so it's now a reasonable time to actually do it.
  ([github.com/kagent-dev/kagent](https://github.com/kagent-dev/kagent/releases/tag/v1.0.0-rc1))
- **Hermes (our harness) crosses 259,710 stars (Δ+2,444)**, still growing fast with daily commits but no headline
  feature this week — routine maintenance pace.
- **CrewAI ships 1.15.34** (Nov 1): standalone LiteLLM model catalog, records where a `crewai run` stops before
  kickoff, and adds `crewai skill search` to list an org's skills — incremental but useful tooling, not architecture.
- **Protocol repos (A2A, MCP, x402) keep steady, modest growth** (+92/+55/+19 stars this week respectively) — no
  releases, just continued adoption momentum on the underlying standards our x402 interest sits on top of.
- **Paper worth reading: "Beyond LLM Wrappers: Context Engineering and the Three-Engine Architecture for Reliable
  Financial AI"** (arXiv 2610.39230, Oct 29) — argues financial AI agents need numerical accuracy, traceability and
  auditability that a bare LLM-wrapper can't give, which is exactly the gap between "an agent writes a trade proposal"
  and "an agent executes a trade" that keeps `trade.py` as our single order path.
- **Reality check: framework stars keep climbing, agent-token prices don't follow.** No AI-agent sector data came
  through in today's pull (CoinGecko block empty), but the pattern from every prior week holds — repo stars are not
  a trading signal, and a token pumping on "AI agents" narrative with no shipped agent (see $XNDR above) is the same
  story as RLC/ARC/FET in prior weeks.
- **Try this week: stand up the read-only kagent ops agent on chkm8-nue-1**, scoped to view-only RBAC (pods/jobs/logs
  for the chkm8 namespace, no write verbs) — now that kagent has an rc1, this is the concrete next step on the
  roadmap rather than a repeated "someday" item. Agents stay proposal-only; `trade.py` remains the sole order path.
