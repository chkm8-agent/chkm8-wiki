# XMR (Monero)

Default-private PoW coin and the purist rival to [[zec]]. Covered daily in [[chains/2026-10-05|Five Chains]].

**Narrative:** privacy without a wrapper: no ETF, little perp OI (Lighter $2.24M). The big upgrade is FCMP++ + CARROT, which takes the anonymity set from 16 decoys to the whole chain. The beta stressnet (v0.19.0.0-beta.3.0) forked on 2026-10-05, with no mainnet date (CMC, CoinStats). Access is fragile after CEX delistings. THORChain demoed RUNE→XMR on a chainnet (THORChain blog), mainnet unconfirmed.

**Decentralization:** 0 (credible). No premine, no foundation token, RandomX CPU mining. Risks are regulatory/delisting, not admin keys.

**CT note:** $XMR samples on 2026-10-05 were 100% "vote on Axiom snapshot" bot spam.
